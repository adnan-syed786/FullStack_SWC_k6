# Q9 Amazon Homepage Clone

Responsive ecommerce homepage inspired by Amazon-style storefront layouts.

## Features

- Header with brand, location, search bar, account links, cart, and quick navigation.
- Responsive hero section.
- Product category cards and deal cards.
- Mobile menu toggle for quick navigation.
- Reusable utility classes such as `container`, `flex`, `grid`, `card`, `btn`, `gap-md`, and `justify-between`.

## How to Run

Open `index.html` directly in a browser.
