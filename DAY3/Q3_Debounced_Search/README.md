# Q8 Debounced Search

Optimized live search for filtering a product list.

## Features

- Input field for searching product names and categories.
- Real-time filtered results.
- Reusable `debounce` helper with a 300ms delay.
- Computation counter to show that filtering is not run on every keystroke.
- Empty state when no products match.

## How to Run

Open `index.html` directly in a browser.
